# Trust boundaries

The browser receives server-side random sessions, never RCON credentials. Tokens are stored as SHA-256 hashes; passwords use Argon2id. Cookies are HttpOnly/SameSite=Strict with 8-hour expiry and optional HTTPS Secure. State-changing APIs enforce exact Origin plus session CSRF token. WebSockets enforce Origin and session authentication and recheck expiry. CORS is not enabled. Sensitive operations are audited with actor/time; command text is deliberately omitted because commands may contain secrets. Viewer role cannot mutate; admin creation/password reset uses the local CLI and revokes existing sessions.

The root-owned helper is the only sudo target. It uses isolated Python (-I), a cleared environment, fixed executable paths, explicit units, fixed roots, no shell, and strict arguments. It never accepts arbitrary systemctl units or commands. Maintenance can only be started, not replaced/stopped/rescheduled. Restore accepts only known archive filenames in completed backup sets, rejects links/devices/traversal, stages data, retains rollback, and preserves current RCON values.

The panel runs as ps5-panel, not root. App/helper/service/config files are root-owned. ACLs grant access only to approved Minecraft roots and read-only backups/maintenance script. Java runs as the existing ps5 account. Installing an executable JAR requires an explicit trust confirmation; plugin/mod code executes with the Minecraft account's permissions when the server loads it. Unrestricted Minecraft commands are also an administrator capability. Do not give admin to untrusted people. Local ps5/root users remain trusted: they can directly change the worlds and services. Filesystem checks reject symlinks at request time; protection against hostile concurrent local directory replacement via openat2 is not yet implemented.

Both root and application services inherit systemd's filesystem sandbox. The helper requires writable /srv/minecraft and /run/lock; Unix ownership/ACLs still prevent non-root panel writes to the backup root. NoNewPrivileges is deliberately absent because it would prevent the narrowly authorized sudo transition. Restoring server data grants panel ACLs after swap. Protection does not claim to sandbox arbitrary hostile Minecraft plugins from the ps5 account's resources.

RCON protocols transmit credentials without encryption; all panel RCON connections go to 127.0.0.1. The inet nftables rule drops non-loopback traffic to 25575/25576 for IPv4 and IPv6. A firewall service is required before either Minecraft service starts. Installer does not flush/replace existing firewall rules. Keep those ports fixed unless updating both configuration and firewall rules.

Administrator full backup downloads inherently include the original server files, possibly old server.properties credentials. Treat downloaded backups and edit/RCON snapshots as confidential. Never publish these directories. No credentials are embedded in the frontend, commands/audit output or source repository.
